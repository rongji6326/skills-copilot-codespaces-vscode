## About the Character Design

The character 松巷·胜石·歌莎毕 is inspired by five beloved anime characters:
- 友利奈绪 (Yuri Nao) from Charlotte
- 千反田える (Chitanda Eru) from Hyouka  
- 宫水三叶 (Miyamizu Mitsuha) from Your Name
- 后藤一里 (Gotou Hitori) from Bocchi the Rock!
- 樱岛麻衣 (Sakurajima Mai) from Rascal Does Not Dream

## Adding New Artwork

If you're an artist and would like to contribute a full character illustration:

1. Follow the design direction in [CHARACTER_PROFILE.md](../CHARACTER_PROFILE.md)
2. Create your artwork (PNG format recommended for final artwork)
3. Name it `character-matsugai-katsuseki-gosabi.png`
4. Submit via pull request

Accepted formats:
- PNG (preferred for final artwork)
- SVG (for vector artwork)
- JPEG (for concept art)
